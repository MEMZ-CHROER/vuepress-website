## ✨ 功能特色

| 特性 | 说明 |
|------|------|
| 🧊 毛玻璃导航 | 沉浸式导航体验 |
| 🌙 暗色模式 | 跟随系统自动切换 |
| 💬 评论系统 | Twikoo 驱动，支持 QQ/微信/邮箱登录 |
| 🎲 每日一句 | 首页随机展示坦克/编程语录 |
| 📊 站点统计 | 6 维数据卡片一目了然 |
| 🪲 页面彩蛋 | 戳左下角小虫子有惊喜 |
| 📱 完全响应式 | 手机/平板/桌面都能看 |
| 🔢 KaTeX 公式 | 支持数学公式渲染 |
| 📊 Mermaid 图表 | 支持流程图/时序图 |

## 🛠️ 技术栈

```
📦 VuePress 2          — 静态站点生成器
🎨 Vite                — 极速构建
💬 Twikoo + Railway    — 评论系统 + MongoDB
🚀 Vercel              — 部署托管
🌐 liuxiyu.cn          — 主站域名
```

## 🚴 本地运行

```bash
# 安装依赖
yarn install

# 启动开发服务器
yarn dev

# 构建生产版本
yarn build
```
