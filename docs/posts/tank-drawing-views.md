# 手绘坦克进阶：侧面 vs 俯视视角，到底怎么画

画坦克有两条腿：**侧面**和**俯视**。初学者大多先画侧面（好上手），但画久了你会发现——俯视图才是展示坦克全貌的关键。这篇讲讲两个视角各自的画法和坑。

## 一、侧面视角：最容易入门

侧面图就是"从旁边看"，主要画车体、炮塔、炮管的**轮廓**。

**画法要点：**

1. 一个扁长的车体矩形 + 上面一个小炮塔 + 一根炮管
2. 履带在下方，包住 5~7 个负重轮（还记得上一篇吗）
3. 炮管长度约等于车体长度

**常见坑：**

- **比例失衡**：炮塔画太大，车体画太小，显得头重脚轻。记住炮塔约占车体长度一半
- **履带画平了**：侧面看履带其实有一点高度，别画成一条细线

## 二、俯视视角：展示全貌的高级视角

俯视图是**从上往下看**，能看到坦克的完整布局——这是侧面图看不到的。

**画法要点：**

1. 车体是一个**大圆角矩形**（俯视下坦克整体是长方形的）
2. 炮塔在车体**正中偏前**的位置，是个小圆角矩形
3. 炮管从这个矩形里伸出来，指向一个方向
4. 两侧是两条履带，宽度约占车体总宽的 1/3

**关键技巧——视角的"假象"：**

俯视图看着难，其实只要抓住"**车体是主矩形，炮塔是上面的小矩形，炮管朝一个方向**"这个骨架，细节都是往上叠加的。

```
    ┌──────────────────┐
    │    [炮塔]  炮管→   │
    │   ▓▓▓▓▓▓▓▓▓▓▓▓   │  ← 两侧履带
    └──────────────────┘
```

## 三、两者怎么选？

| 场景 | 推荐视角 |
| ---- | -------- |
| 新手入门练手 | 侧面 |
| 展示坦克完整设计 | 俯视 |
| 画"帅气侧影" | 侧面 |
| 画"设计图纸/设定稿" | 俯视 |

## 四、进阶：两个视角配合用

真正专业的设计稿，会**同时画侧面和俯视**（甚至加一个前视图）。这样别人一眼就能看懂这辆坦克到底长什么样。

我自己的习惯是：先用侧面定"气质"，再用俯视定"布局"，两个一配合，一辆坦克就立体起来了。

## 小结

1. 侧面好上手，画轮廓、注意比例
2. 俯视看全貌，抓"大矩形 + 小矩形 + 炮管"骨架
3. 专业设计稿：侧面 + 俯视一起画

画多了你会发现，**视角只是看坦克的一种方式，骨架永远都是那套**。把骨架练熟，什么角度都不怕。
