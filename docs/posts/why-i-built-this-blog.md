# 我的建站之旅：一张 git 提交历史讲完的故事

很多人问：为什么自己搭一个博客？其实答案很简单——**我想给坦克一个家，然后学着当一个"站主"**。今天不讲大道理，就翻出我的 git 提交历史，按时间线把它讲一遍。这些 commit 就是我这个网站最真实的成长日记。

## 🏁 2024-03：一切的开端

> `abf6541` Initial commit（2024-03-23）

最初只是"Add files via upload"——一堆文件直接拖上来。网站的第一版，其实就是个**坦克展示页**，把我画的手绘坦克放上去，给它们一个存证。

接着几天内：加了 fujian（附件）、加了第三个页面、加了 GitHub 标签。**边学边搭**，那时候连 git 都玩不转，提交信息一堆 `update`、`commit changes`，现在看有点好笑，但那就是真实的起步。

## 🚀 2024-04~06：正式上线 + 换包管理器

- 2024-04：接入 Vercel，网站开始**自动部署**
- 2024-05：`659db00 用yarn顶掉npm的安装`——正式从 npm 换到 yarn
- 2024-06：`b4db031 update logo`——定制了自己的 logo，网站开始有自己的"脸"

这个"yarn 接管"其实是个分水岭。从这以后我慢慢懂了**依赖管理**是什么，也第一次体会到"包管理器"这种基建有多重要。

## ⚙️ 2025：折腾的一年

**2025-01**：`885c2ed 尝试文件上传`——开始想给网站加上传下载功能。

**2025-05**：一段很真实的"挣扎"：

> `39fb3f4 更新vuepress到2.0.0-rc.13` → `c95b465 测试失败，降级到2.0.0-rc.11` → `174e282 挣扎`

那段时间在升 vuepress 版本上反复横跳，踩坑、回滚、再试。虽然折腾，但这正是**最锻炼人的部分**。

**2025-08**：坦克大扩充的一个月——`c382e60 增加坦克数量`、`4b46fe7 坦克集齐` 🎉 三十多辆手绘坦克终于齐了；`1a211df 加入种花页面` 奶茶杯里养的枇杷树也上线了。

**2025-09~11**：`c66a4c1 加入信息课展示`，然后不断调整、补页面，`247987e 加入CSS学习页面`。网站从一个坦克页，慢慢长成了**一个真正的内容站**。

## ✨ 2026-05~07：功能大爆发

**2026-05**：`2f73889 增加备案号`——给网站办了 ICP 备案，正式有了"合法身份"。

**2026-07** 是最疯狂的一个月，密集的提交堆出了一个更完整的站：

- `0c7034e UI美化：全新按钮系统、毛玻璃导航、渐变文字、暗色模式`
- `fabb42d 评论系统更换为 Twikoo`（从 Giscus 换到 Twikoo，支持 QQ/微信/邮箱登录）
- `883fbbd 新增：友情链接页面 + 小彩蛋组件（戳🪲有惊喜）`
- `58bda76 新增：首页统计面板 + 关于页面`
- `4f38222 新增：sitemap 站点地图`、`db130d5 新增：RSS/Atom 订阅功能`
- 还有 `0c7034e` 那套毛玻璃导航背后，其实是好几个 `fabb42d`、`58bda76` 这样的小提交一点点堆起来的

## 🔧 2026-08：最难啃的硬骨头

这个月是**密集折腾**的一个月，也是踩坑最多、成长最快的一个月。

**先说版本锁定 rc.30**。之前把 vuepress 一路升上去，结果撞了一堆问题。8-20 那天连续几条提交，就是一段真实的拉锯战：

> `8381295 回滚VuePress版本到rc.30稳定` → `ce43f38 锁定Vuepress+Vite版本为rc30` → `d7630c7 Add One Click Deploy Command`

反复升、反复回滚，最后确定：**vuepress 和 bundler-vite 锁死在 rc.30**，配套 theme-hope，才稳定下来。还顺带加了一条一键部署命令（`yarn deploy`）。

**修 SSR 污染 bug**（`48c8c96`）：

> 所有页面的 `<title>` 被 404 页面污染、body 被首页污染。

这个 bug 是升级带来的连锁反应，最后靠锁定 rc.30 + 打补丁解决。升级依赖一时爽，降级排查火葬场，就是这个道理。

**迁移 theme-hope**（`1d2f74e`）：

> 从默认主题迁移到 theme-hope，启用图片预览、复制、阅读时间、目录、全文搜索 + 离线 PWA。

这是整个 8 月的重头戏。主题迁移不是换个主题那么简单——插件链全得重新配，很多功能都是靠 `a8c13cb 启用 theme-hope 扩展插件` 一条一条加回来的。

**其他大事**：

- `03c50ea` 上线 FAQ 上传下载（Vercel Blob + serverless）
- `7201b57` 新增全文搜索 + 离线 PWA
- `b7104bd` bundler-vite 放开版本为 ^rc.30
- `fe34f1b` 加 **GitHub Pages 备份站**，以后 Vercel 不可靠时 `cdn.liuxiyu.cn` 就是第二张牌
- `f65017c` 清理 16 篇占位文章，让站里只留真内容

## 📖 数据说话

翻完这 176 条提交，几个数字很有感觉：

- **起步**：2024 年 3 月，一个坦克展示页
- **现在**：坦克、编程、种花、信息AI、随笔……什么都有了
- **经历**：yarn 迁移、Vercel 部署、vuepress 升级挣扎、SSR 修 bug、theme-hope 迁移、双平台部署

## 💭 写在最后

回头看，这个网站最大的意义不是"我做了个好看的博客"，而是**我为了它学会了太多东西**：

- 为了部署，学会了 git、yarn、Vercel
- 为了修 bug，学会了看依赖、打补丁、降级排查
- 为了加功能，学会了 serverless、全文搜索、PWA

每一行 commit 背后，都是一次真实的踩坑和学习。

**我的博客，我的地盘，我的世界。** 感谢每个逛到这个网站的你——我会继续画坦克、学编程、写奇思妙想，然后把它们一条一条 commit 进这个小站。
