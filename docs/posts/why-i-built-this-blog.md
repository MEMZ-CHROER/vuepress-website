# 我为什么要自己搭一个网站博客

经常有人问我：写文章发在公众号、知乎上不就行了吗，干嘛费劲自己搭一个网站？今天就来聊聊我建这个博客的初衷。

## 一、一开始，只想给坦克一个家

这个网站最开始，其实就是个坦克展示页——把我画的手绘坦克都放上去，给它们一个"存证"。那时候没想过做博客，纯粹是想**把自己喜欢的东西好好收着**。

后来发现，光看图不过瘾，想说说每辆坦克的设计思路、起名缘由，于是就有了第一篇文字。

## 二、为什么不用现成的平台？

说实话，公众号、知乎这些我也用过，但总觉得差点意思：

- **排版不是我想要的**：想加个特殊样式，平台不支持，憋得慌
- **内容不归我管**：万一平台改版、删内容，辛辛苦苦写的东西就没了
- **不够"自己"**：博客想要什么样的结构、什么风格，都得自己定，这才有归属感

**自己的地盘，自己说了算**——这就是自己搭站最大的好处。

## 三、搭站过程中的意外收获

搭这个站的过程，本身就是一次超大的学习：

- 从零搞懂 VuePress 怎么配置、怎么部署
- 学会了 git 怎么管理、怎么自动部署上线
- 踩了无数坑（比如版本不对构建失败），但也因此学到了真东西

**建站本身就是最好的编程实践课。** 为了搞定一个功能，你会主动去学很多平时懒得碰的知识。

## 四、把想法都倒出来

这个博客现在有坦克、有编程、有奇思妙想——什么都有。因为我就想把它当成一个**尽情记录的地方**：

- 画了辆新坦克？发上来
- 学了个新知识点？记下来
- 脑子冒出奇怪想法？写出来

不用管别人怎么看，**写给自己看**，顺便分享给志同道合的人。

## 五、写在最后

如果你也想有自己的博客，我特别推荐自己搭一个试试。刚开始可能很麻烦，但当你第一次看到自己搭的网站在线跑起来时，那种成就感是发多少篇公众号都给不了的。

**我的博客，我的地盘，我的世界。**
