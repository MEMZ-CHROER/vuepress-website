# 如何画一辆好看的手绘坦克

画坦克这事儿，看着难，其实有套路。只要抓住几个关键点，从"画得像坨铁盒子"到"一眼就知道是坦克"，只差这几步。

## 一、先定轮廓，再画细节

很多人一上来就抠炮管上的铆钉，结果整体比例崩了。正确顺序是：

1. 先用简单的几何形状框出整体：一个扁长的**车体** + 一个**炮塔** + 一根**炮管**
2. 确认三者的大小比例，车体是主体，炮塔约占车体长度的一半，炮管长度约等于车体
3. 轮廓顺眼之后，再开始加细节

记住一句话：**轮廓错了，细节再多也是白画**。

## 二、炮管要长，装甲要厚

我们博客的名言不是白说的。好看的坦克，姿态都藏在这两句话里：

- **炮管要长**：炮管长，显得有气势、有威慑力。炮管微微上抬一点，比水平更有攻击性
- **装甲要厚**：车体正面画得宽厚，履带部分留足高度，整体看起来"结实"而不是"单薄"

画的时候，可以给车体侧面加一点**斜切面**，比直上直下更立体、更有真实装甲的感觉。

## 三、履带是灵魂

一辆坦克是不是坦克，看履带就对了。履带画不好，整车都露馅。

几个小技巧：

- 履带要**包住负重轮**，负重轮一般是 5~7 个圆，间距均匀
- 履带上缘比下缘稍窄，形成一点梯形，符合透视
- 在履带表面加一排小方块或斜纹，表示履带板纹路

::: tip
先画负重轮，再顺着轮子的轮廓画履带，比反过来容易得多。
:::

## 四、用色彩制造"活"的感觉

线稿画完，上色时注意这三点：

1. **先铺大色块**（车体、炮塔、履带各自的基础色），别急着画高光
2. **明暗对比**：光源在左上，那么右上亮、左下暗。加一点暗部，立体感立刻出来
3. **旧化效果**：在履带和车体下缘蹭一点深色，模拟泥土和磨损，比崭新的车有味道

## 五、细节是加分项，不是必需项

天线、工具箱、烟雾弹发射器、车体侧裙板……这些细节加对了很出彩，但**比例没对之前，先别加**。

我自己的习惯是：先画到"一眼能认出是坦克"，停一晚上，第二天再看，觉得哪里别扭再改。画完之后放一放再回头挑毛病，比连续画十个小时效率高得多。

## 总结

画坦克的四步口诀：

1. 几何框轮廓，比例先对
2. 炮管长、装甲厚，姿态有气势
3. 履带包轮子，灵魂不能丢
4. 大色块→明暗→旧化，最后才加细节
