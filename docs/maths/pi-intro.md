# 🥧 圆周率 π 的趣味入门

> 从一个圆的秘密说起。

## 什么是 π？

任何圆的周长 ÷ 直径，算出来的结果都是同一个数，约等于 **3.14159...**，我们叫它 **π**（读作"派"）。

```
周长 = π × 直径
面积 = π × 半径²
```

## π 的惊人特性

- **无限不循环**：小数点后永远写不完，也永远不重复。目前已经算到几十万亿位。
- **用 3.14 就够用**：日常计算用 3.14 或 22/7 就足够精确了。
- **藏在很多地方**：不只是圆，摆动、波、概率里都有 π 的影子。

## 有趣的记忆法

- **3.14159** 谐音："山巅一寺一壶酒" 🍶
- 用更多位："山巅一寺一壶酒，尔乐苦煞吾"（3.1415926...）

## 你能自己验证吗？

拿一个圆形的杯盖，用绳子量一圈周长，再用尺子量直径，两者相除——你会发现结果**接近 3.14**！这就是亲手发现 π 的乐趣。
