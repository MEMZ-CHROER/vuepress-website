# 以色列旅行文化礼仪清单：畅游以色列必备

这里为你清晰梳理以色列的**自然环境特点**与**人文习俗**的核心内容：

### 自然环境特点

1. **地理位置与地形**：位于亚洲西部、地中海东岸，亚非欧三洲交界处；国土狭长，地形多样。西部是地中海沿岸平原（主要农业区）；中北部为山地丘陵（最高峰梅隆山1208米）；南部的**内盖夫沙漠**占国土一半以上；东部约旦河谷是东非大裂谷延伸，**死海**为世界陆地最低点（-430米左右），加利利湖是最重要的淡水湖。

2. **气候**：北部与沿海是典型**地中海气候**，夏季炎热干燥、冬季温和多雨；南部沙漠为**热带沙漠气候**，全年干旱少雨，温差极大。降水分布极不均，北部年降水量可达900mm，南部沙漠仅30mm左右。

3. **水资源与植被**：淡水资源极度匮乏，靠海水淡化、污水回用、节水农业支撑；植被呈带状分布，北部有森林、灌丛，南部沙漠以耐旱植物为主；矿产资源不丰富，有钾盐、石灰石、铜等。

### 人文习俗

1. **人口与语言**：以犹太人为主体（约75%），阿拉伯人约20%；官方语言是**希伯来语**和**阿拉伯语**，英语广泛通用；希伯来语从宗教文献语言复兴为日常用语是文化奇迹。

2. **宗教与核心传统**

    - 主要宗教是**犹太教**，另有伊斯兰教、基督教群体；犹太教对日常生活影响深远。

    - **安息日**：周五日落至周六日落，传统社区商店、公交基本停运，人们团聚祈祷，不从事劳作；

    - **犹太洁食（Kosher）**：禁食猪肉、贝类等；肉类与奶制品不可同食且需分开餐具；

    - 问候常用 **Shalom**（意为和平，兼作你好、再见）。

3. **重要节日**

    - 逾越节（3-4月）：纪念出埃及，家宴吃无酵饼；

    - 犹太新年、赎罪日（9-10月）：重要的忏悔与祈祷节日；

    - 光明节（12月左右）：8天，点燃烛台，吃油炸土豆饼、果酱甜甜圈，儿童玩陀螺。

4. **饮食与文化**：传统美食有**法拉费（炸鹰嘴豆丸子）**、**鹰嘴豆泥（Hummus）**、沙威玛、烤鱼；流行霍拉舞（人们手拉手围成圈跳舞）；兼具宗教传统底蕴与移民带来的多元现代文化。
