# 🌱 从一颗枇杷核开始：水培观察日记

> 一杯水 + 一颗枇杷核，就能见证生命的奇迹。

## 为什么选枇杷核？

吃枇杷时剩下的核，本来要扔进垃圾桶——但它其实藏着一个小生命。奶茶杯二次利用，就成了它的"家"。

## 水培步骤（超简单）

1. **洗净核**：把果肉清理干净，别留残留物，否则容易发霉
2. **泡水催芽**：核泡在清水里 1-2 天，帮助外壳软化
3. **半浸半露**：用奶茶杯装水，让核一半泡水、一半露在空气中
4. **耐心等待**：放窗边有散光处，隔几天换一次水

## 观察记录

| 时间 | 变化 |
|------|------|
| 第 1 周 | 外壳微微裂开，冒出小芽尖 |
| 第 2 周 | 根须向下生长，芽向上抽长 |
| 第 3-4 周 | 长出第一片真叶，幼苗成型 |

## 小贴士

- **别晒太阳直射**：散光最好，暴晒会让芽脱水
- **勤换水**：防止水变臭、滋生细菌
- **破壳加速**：如果壳太硬，可以轻轻剥开一点（小心别伤到芽）

---

一颗不要的果核，变成一棵小苗——这是种花最治愈的地方。🌿
