# 🖥️ 我的第一份编程笔记

> 用最简单的话，讲清楚编程到底是什么。

## 什么是编程？

编程就是**给计算机下达指令**，让它按照你的想法去执行任务。就像写菜谱一样，你告诉计算机每一步该做什么。

## 最基础的概念

### 1. 变量（Variable）

变量是**用来存东西的盒子**。每个盒子有名字，里面可以放数字、文字等。

```csharp
int age = 12;        // 存一个整数 12
string name = "Lxy"; // 存一段文字 "Lxy"
```

### 2. 条件判断（if）

让程序"看情况做事"：

```csharp
if (age >= 18)
{
    Console.WriteLine("成年了");
}
else
{
    Console.WriteLine("还是小朋友");
}
```

### 3. 循环（Loop）

让程序**重复做事**：

```csharp
for (int i = 1; i <= 5; i++)
{
    Console.WriteLine("第" + i + "次");
}
```

## 为什么要学编程？

- 锻炼**逻辑思维**：像解题一样拆解问题
- 创造**自己的工具**：做游戏、做网站、自动化任务
- 学会**和机器对话**：理解现代科技是怎么运作的

## 学习建议

1. **多动手**：光看不练假把式，每个例子都敲一遍
2. **从简单开始**：先掌握变量、判断、循环这"三板斧"
3. **不怕报错**：错误是老师，看懂报错信息就能进步
